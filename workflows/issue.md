# issue — 本月該開的 SCAR 開一開

1. 讀 `inbox/` 指示（若有）。
2. 讀 `data/本月進料異常記錄.csv`，先回報一行「已讀取 X 列」。
3. 依供應商統計：筆數、佔比、判定分布、同缺陷再發週次（週次見 `knowledge/01`）。
4. 依門檻決定開單名單與觀察名單。
5. 寫產出到 `outbox/`（每檔 `> 狀態：待確認`）：
   - `YYYY-MM-DD_供應商統計.md`：六家一表＋開單決定與依據
   - `SCAR-YYYYMMDD-00N_供應商.md`：每家一份，格式完全照 `knowledge/02`
   - `YYYY-MM-DD_寄件信_供應商.md`：每份 SCAR 一封
   - `YYYY-MM-DD_回覆追蹤表.csv`：SCAR 編號、供應商、發行日、根因期限、措施期限、狀態、我方窗口
   - `YYYY-MM-DD_內部月報摘要.md`：給品保主管的一頁（開單、觀察、下月要盯的）
6. `log/scar_log.md` 加一列。
7. 依 `knowledge/03` 三行交件。

## 不准做的
不寄、不編數據、不在 SCAR 裡寫別家供應商、不替供應商寫根因。
